# 图像/文件图标提取工具

一个现代化的图标提取工具，使用 CustomTkinter 构建，提供美观的用户界面和强大的功能。

## 🎨 界面特性

### 现代化设计
- **CustomTkinter UI**: 使用现代化的 CustomTkinter 框架
- **明暗主题**: 支持明暗主题切换 (🌙 按钮)
- **响应式布局**: 自适应窗口大小调整
- **高DPI支持**: 完美支持高分辨率显示器

### 用户体验
- **进度指示**: 提取和保存过程显示进度条
- **视觉反馈**: 选中图标有明显的视觉反馈
- **实时预览**: 选择图标后立即显示预览
- **状态提示**: 底部状态栏显示操作状态

## 🚀 功能特性

### 支持的文件格式
- **图像文件**: PNG, JPG, JPEG, WEBP
- **可执行文件**: EXE, DLL (提取内置图标)
- **快捷方式**: LNK (提取目标文件图标)

### 输出选项
- **多种尺寸**: 16x16 到 256x256 像素
- **ICO格式**: 标准Windows图标格式
- **高质量**: 使用LANCZOS算法保证图像质量

## 🎯 使用方法

1. **选择输入文件**: 点击"浏览"按钮选择源文件
2. **选择图标**: 从提取的图标列表中选择需要的图标
3. **设置尺寸**: 选择输出图标的尺寸
4. **预览确认**: 在预览区域查看效果
5. **保存图标**: 点击"保存图标"按钮导出

## 🛠️ 技术实现

### 核心技术
- **CustomTkinter**: 现代化GUI框架
- **PIL/Pillow**: 图像处理
- **Win32API**: Windows系统图标提取

### 界面组件
- **CTkFrame**: 容器组件
- **CTkButton**: 按钮组件
- **CTkScrollableFrame**: 可滚动图标列表
- **CTkProgressBar**: 进度指示器
- **CTkRadioButton**: 尺寸选择
